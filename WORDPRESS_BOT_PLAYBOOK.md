# WORDPRESS_BOT_PLAYBOOK

Готовые команды для бота-помощника по WordPress (AZMODA)

## 1) Контент и страницы
- "Создай страницу 'Доставка и оплата' в стиле бренда AZMODA, структура: hero, условия доставки, оплата, FAQ, CTA." 
- "Обнови главную: сделай более продающий первый экран, добавь 3 преимущества и блок хитов продаж."
- "Перепиши текст на странице 'О нас' в премиальном, лаконичном тоне."

## 2) WooCommerce товары
- "Создай карточку товара: название, короткое описание, полное описание, характеристики, meta title/description, slug."
- "Сгенерируй 10 SEO-описаний для категории 'Женская обувь' без воды, с упором на конверсию."
- "Сделай шаблон описания для одежды: материал, посадка, размерная сетка, уход, доставка."

## 3) SEO и структура
- "Проведи SEO-аудит страницы /shop и выдай список из 10 правок по приоритету (high/medium/low)."
- "Сделай title/description для 20 товаров по шаблону бренда AZMODA."
- "Проверь URL-структуру и предложи clean slugs для категорий и товаров."

## 4) Elementor
- "Собери секцию hero для главной в стиле премиум-маркетплейса: H1, subtitle, CTA, баннер."
- "Дай точные настройки отступов/типографики для mobile/tablet/desktop."
- "Подготовь HTML-блок для Elementor с адаптивом и без конфликтов со стилями темы."

## 5) Скорость и качество
- "Проверь, что тормозит сайт, и дай план ускорения в 3 этапа: быстро/средне/глубоко."
- "Составь безопасный чеклист перед каждым обновлением плагинов."
- "Дай регламент бэкапа: ежедневный, недельный, перед релизом."

## 6) Ежедневный режим (короткие задачи)
- "Дай план задач на сегодня по WordPress на 60 минут: 3 пункта, максимум результата."
- "Оцени текущую страницу как UX-ревьюер и дай 7 правок, влияющих на продажи."
- "Проверь текст и убери всё, что мешает конверсии."

---

## Мини-чеклист подключения к реальному сайту
Нужно 3 вещи:
1. URL сайта (пример: https://azmoda.shop)
2. Логин админа WordPress
3. Application Password (WordPress → Users → Profile → Application Passwords)

После этого бот можно полноценно подключить к REST API и работать с контентом/товарами напрямую.
